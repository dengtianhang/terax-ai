## REQ-001：界面语言切换

- 状态：待处理
- 优先级：P1
- 背景：不同用户需要中文或 English 界面，并希望首次使用时减少配置成本。
- 需求：支持中文 / English；首次启动跟随系统语言；用户选择持久化。
- 验收标准：
  - 可在设置中切换中文和 English。
  - 未保存用户选择时，界面跟随系统语言。
  - 重启 Terax 后保留用户选择。
  - 切换语言后主要界面文案同步更新。

## REQ-002：终端颜色调优

- 状态：待处理
- 优先级：P2
- 背景：浅色主题下部分 ANSI 颜色对比度不足，影响终端内容阅读。
- 需求：调优浅色主题 ANSI 调色板，确保常用颜色在终端背景上保持可读。
- 验收标准：
  - 常用 ANSI 颜色在浅色主题下清晰可辨。
  - 普通文本、提示符、错误信息和选中文本保持足够对比度。
  - 深色主题现有颜色表现不被破坏。

## REQ-003：PowerShell ANSI 输出自动启用

- 状态：已完成
- 优先级：P1
- 背景：PowerShell 默认环境可能未启用 ANSI 输出，导致终端颜色和控制序列显示异常。
- 需求：仅在 Terax 启动的 PowerShell 会话中自动启用 ANSI 输出，不修改用户 `$PROFILE`。
- 验收标准：
  - Terax PowerShell 会话支持 ANSI 输出。
  - 用户系统 PowerShell 配置不被修改。
  - Terax 外部启动的 PowerShell 行为不受影响。

## REQ-005：图片预览

- 状态：已完成
- 优先级：P2
- 背景：工作区中的图片和 Markdown 本地图片需要在 Terax 内直接预览。
- 需求：Tauri 资源范围覆盖工作区图片文件；Markdown 本地图片通过 Blob URL 加载。
- 验收标准：
  - 文件浏览器可预览工作区中的常见图片格式。
  - Markdown 可加载工作区内的本地图片。
  - 图片访问不突破工作区资源范围。
  - 图片不存在或读取失败时显示可理解的错误状态。

## REQ-006：项目文件夹切换

- 状态：已完成
- 优先级：P1
- 背景：用户需要在同一个 Terax 窗口中切换项目工作区。
- 需求：选择本地目录后切换当前工作区，并重置与旧工作区相关的状态。
- 验收标准：
  - 可通过目录选择器选择新的本地工作区。
  - 切换后文件浏览器、终端工作目录和 Git 状态指向新工作区。
  - 旧工作区状态不会错误显示在新工作区。
  - 用户取消选择时保留当前工作区不变。

## REQ-007：启动工作区恢复

- 状态：进行中
- 优先级：P1
- 背景：用户不希望应用启动时自动创建无意义的终端，同时需要保留上次工作状态。
- 需求：首次启动或没有历史 Tab 时保持空白；存在历史 Tab 时恢复上次 Tab。
- 验收标准：
  - 首次启动不自动创建终端。
  - 重启应用后恢复上次保存的 Tab 和活动 Tab。
  - 历史 Tab 为空时保持空白工作区。
  - 用户可通过新建按钮主动创建终端。
